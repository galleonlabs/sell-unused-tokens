# Security

This repository is archived and contains only a migration pointer. It does not contain the current Tokensto.cash CLI or agent API implementation.

The maintainer check `scripts/validate.sh` is the only executable file shipped here. It validates this pointer repository and does not read credentials.

Install the current skill from https://tokensto.cash. Never put provider keys or pairing codes in GitHub issues, pull requests, chat, command arguments, or logs. Rotate any provider key that has been exposed.

Report security issues to gm@galleonlabs.io.
